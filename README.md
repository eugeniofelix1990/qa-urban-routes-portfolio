# QA Urban Routes Portfolio

Professional QA Automation & API Testing portfolio demonstrating rigorous test design, data-driven testing (DDT), and automated test execution scripts developed across multiple project sprints.

---

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **API Testing & Automation:** Requests library, Custom Test Runners (`engine/`)
- **Data Management:** JSON Datasets (`data/`), CSV Test Reports
- **Version Control & Environment:** Git, Linux Mint Terminal
- **Manual QA & Analysis:** Postman, Test Artifacts & Checklists
